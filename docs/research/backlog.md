# Research backlog

## First pass — define a fair comparison

- [ ] Confirm US/USD scope and initial product/customer segment.
- [ ] Discover and verify strictly single-product candidates.
- [ ] Classify each candidate by current assortment.
- [ ] Select one comparable plain white crew-neck tee per included brand.
- [ ] Record source URLs and actual access dates.

## Second pass — complete the profiles

- [ ] Capture product specifications and comparable unit pricing.
- [ ] Review shipping and returns under consistent conditions.
- [ ] Document positioning, design choices, and shopping experience.
- [ ] Gather customer evidence with limitations.
- [ ] Update the comparison matrix from sourced observations.

## Third pass — decide what to test

- [ ] Interview potential customers.
- [ ] Identify recurring needs and differences among alternatives.
- [ ] Draft an opportunity brief with supporting source IDs.
- [ ] Decide which assumptions need product testing before brand development.

## Definition of done for a profile

The [method checklist](./method#completion-checklist) is complete, every factual claim has a dated source, unknowns remain explicit, and interpretations are clearly labeled.
